## 💡 How to Capture Full-Page Screenshots
- In Chrome / Edge: Press `Ctrl + Shift + I` $\rightarrow$ `Ctrl + Shift + P` $\rightarrow$ type **"Capture full size screenshot"**.
- Save the images into this folder (`website_screenshots/`) with the filenames above.
